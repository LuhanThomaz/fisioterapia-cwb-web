# Clínica Adriana Silva — Landing Page

Landing page em Next.js (App Router) e TypeScript para apresentar a clínica de fisioterapia. Pensada para evoluir futuramente com área logada de profissionais e pacientes.

## Rodando localmente

1. Instale as dependências: `npm install`
2. Ambiente de desenvolvimento: `npm run dev`
3. Build de produção: `npm run build` e `npm start`
4. Checagem de tipos: `npm run type-check`
